# وردي وتسبيحي 🌿

مشروع Flutter أولي لتطبيق عربي للتسبيح والأوراد المكتوبة يدويًا وتنبيهات الصلاة.

## رفع المشروع وبناء APK من الهاتف عبر GitHub

1. نزّل ملف ZIP وفك ضغطه على الهاتف أو الكمبيوتر.
2. افتح GitHub وأنشئ مستودعًا جديدًا باسم `wardi-tasbehi`.
3. ارفع **محتويات المجلد** إلى المستودع، وليس ملف ZIP نفسه. تأكد من رفع المجلد المخفي `.github` وداخله `workflows/build-apk.yml`.
4. افتح تبويب **Actions** في المستودع.
5. اختر **Build Android APK** ثم اضغط **Run workflow**. ويمكن أن يبدأ البناء تلقائيًا بعد رفع الملفات إلى فرع `main`.
6. انتظر حتى تصبح نتيجة التشغيل خضراء، ثم افتح التشغيل وابحث عن **Artifacts**.
7. نزّل `wardi-tasbehi-apk`، وفك ضغطه، ثم ثبّت `app-release.apk` على هاتف Android.

## ما يتضمنه الإصدار الأولي
- عداد تسبيح وأذكار مع اختيار الذكر وتحديد الهدف.
- إضافة أدعية يدوية وحفظها محليًا مع عداد لكل دعاء.
- طلب موقع الهاتف وحساب مواقيت الصلاة بطريقة الحساب المصرية.
- جدولة تنبيهات الصلوات المتبقية في اليوم عند فتح صفحة الصلاة.

## ملاحظات مهمة قبل الاعتماد اليومي
- هذا **مشروع مصدر** وليس APK جاهزًا الآن؛ ملف APK ينتج بعد نجاح GitHub Actions.
- يجب السماح بإذن الموقع والإشعارات عند الطلب.
- الإصدار الحالي يبرمج تنبيهات الصلوات المتبقية لليوم فقط عند الضغط على زر إعداد التنبيهات؛ لم نضف بعد إعادة الجدولة التلقائية للأيام التالية أو إعدادات صوت التنبيه أو تذكيرات الأوراد بوقت يختاره المستخدم.
- يجب اختبار دقة المواقيت والإشعارات على الهاتف؛ إعدادات توفير البطارية وإصدارات Android قد تؤثر في وصولها.
